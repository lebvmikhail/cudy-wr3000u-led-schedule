# Проверка и возврат исходных настроек

Этот документ дополняет [основную инструкцию](../README.md) для Cudy WR3000U.

## Перед изменениями

1. Создайте резервную копию конфигурации через LuCI: **Система → Резервное копирование / Прошивка**.
2. Сохраните исходную таблицу LED (скриншоты LuCI или копию соответствующих LED-секций `/etc/config/system`).
3. Запишите текущие значения системного времени и часового пояса.

Не рассчитывайте, что один снимок экрана заменит резервную копию конфигурации.

## Контрольный список проверки

- [ ] Все семь LED-правил созданы и сохранены в указанном порядке.
- [ ] WAN реагирует на передачу и приём трафика.
- [ ] LAN реагирует на линк и сетевую активность.
- [ ] Wi-Fi 2.4 GHz и 5 GHz реагируют на соединение и активность.
- [ ] В 21:30 индикаторы выключаются.
- [ ] В течение ночи ежеминутное задание удерживает индикаторы выключенными.
- [ ] После тестовой ночной перезагрузки cron снова выключает индикаторы после запуска.
- [ ] В 07:00 конфигурация LED восстанавливается: постоянные индикаторы горят, сетевые LED снова реагируют на события.

Проверяйте поведение после ночной перезагрузки отдельно: сам факт успешной загрузки роутера ещё не подтверждает работу cron.

## Возврат к исходным настройкам

1. Удалите три добавленные строки расписания из **Система → Планировщик**, сохраните изменения и перезапустите службу cron.
2. В **Система → Индикаторы** верните прежнюю таблицу LED из сохранённой копии или восстановите исходные LED-секции `/etc/config/system`.
3. Примените изменения в LuCI.
4. Выполните по SSH от root:

   ```sh
   /etc/init.d/led restart
   ```

5. Проверьте обычную работу всех индикаторов.

Полное восстановление ранее скачанного архива конфигурации LuCI может затронуть и другие настройки, изменённые после создания архива. Не загружайте старый полный архив только ради возврата LED, если за это время менялись сеть, Wi-Fi, firewall или другие параметры.
